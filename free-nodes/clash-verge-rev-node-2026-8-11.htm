一、什么是Shadowrocket？

Shadowrocket 是一款专为 iOS 平台打造的网络代理工具，功能强大且配置灵活，主要用于设置代理、实现加密流量转发，从而突破地域或网络限制，同时保障用户的上网安全与隐私。

其核心特点如下：

  • 协议支持广泛：支持 Shadowsocks、Vmess、Trojan、HTTP、HTTPS、SOCKS5 等多种协议；

  • 规则灵活：可自定义规则分流，按域名/IP/应用进行流量分类管理；

  • 流量统计详细：实时监控上传/下载速度，帮助用户精确了解网络使用情况；

  • IPv6支持完善：适配现代网络环境；

  • 兼容订阅功能：一键导入节点，动态更新配置文件，极大方便用户维护节点列表。

对于追求隐私、自由、性能的iOS用户来说，Shadowrocket几乎是必不可少的工具。

三、Shadowrocket的基础配置教程

1. 添加代理节点

Shadowrocket支持手动输入节点或通过订阅链接一键导入节点列表。推荐使用订阅链接方式，便于统一管理与自动更新。

方法一：手动添加

  • 打开Shadowrocket；

  • 点击右上角“+”图标 → 选择节点类型（如Shadowsocks、Vmess等）；

  • 填入服务器信息：地址、端口、密码、加密方式等；

  • 保存后即可看到节点出现在列表中。

方法二：使用订阅链接导入

  • 获取订阅地址（如Clash牧场或Telegram群中分享的）；

  • 打开Shadowrocket → 点击“配置” → 添加配置 → 输入订阅URL；

  • 命名后保存，并点击右上角刷新按钮同步节点。

多数节点提供商都会提供兼容Shadowrocket的专用链接。

2. 设置规则分流（可选）

Shadowrocket支持多种代理模式：

  • 全局代理：所有流量均通过代理；

  • 规则模式：按域名/IP或国家归属进行智能分流；

  • 绕过大陆地址：国内流量直连，境外流量代理。

你可以通过添加公共规则集（如ACL4SSR）来自动化管理：

  • 打开“配置”；

  • 点击“规则” → “远程规则”；

  • 添加远程规则地址（例如GitHub上的规则订阅）；

  • 启用该规则配置。

3. 启用代理

  • 配置完成后，返回主界面；

  • 点击右上角开关按钮，首次启用会提示添加VPN配置；

  • 点击“允许”，输入设备密码，授权后将自动建立VPN隧道；

  • 状态栏显示VPN图标，即表示代理已启动成功。

四、使用技巧与进阶配置

✅ 配合第三方DNS使用

推荐搭配 DoH（DNS over HTTPS）服务，如Cloudflare的 1.1.1.1，增强域名解析隐私性与准确性。

路径：设置 → DNS → 添加 → 选择 DoH → 输入地址。

✅ 绑定特定应用使用代理

可开启“分应用代理”模式，仅对部分App启用代理，如YouTube、Telegram等，节省流量并提高效率。

路径：设置 → 应用规则 → 添加 → 选择App → 指定代理方式。

✅ 实时测速与节点切换

长按某个节点可进行测速，数值越小表示连接延迟越低；推荐根据延迟情况选择速度最佳节点。

✅ 多配置切换

支持保存多个配置文件，适用于不同场景（如工作/娱乐/旅行），在主界面一键切换。

FAQ

Potatso Lite 能否兼容最新的 iOS 系统？
Potatso Lite 更新频率较低，在新版本 iOS 上可能出现兼容性问题。若遇到无法连接或闪退情况，建议升级至其他活跃维护的客户端如 Shadowrocket 或 Quantumult X。
V2Ray 的 outbound freedom 模式有什么作用？
freedom 是直连模块，可用于分流策略中实现部分流量直连。用户可在 routing 中设置匹配规则，将国内域名或局域网 IP 指向 freedom 出口，从而减少代理开销和延迟。
Hiddify Next 如何为不同用户设置流量限制？
管理员可为每个用户设置独立带宽限制和流量配额。超过限制时，可自动降速或阻止访问，确保服务器资源合理分配，避免单用户占用过多带宽，提升整体网络效率和公平性。
Netch 如何为游戏流量提供加速？
Netch 支持 UDP 转发，可为游戏流量建立高速通道。结合策略组和节点延迟检测，可减少丢包和延迟，保证游戏访问稳定流畅，提高网络体验。
Shadowrocket 在使用订阅时要注意什么？
在 Shadowrocket 中添加订阅时，应确保链接以 https 开头且格式正确。此外，若节点更新失败，可尝试关闭缓存或重新获取订阅链接，以保证配置文件同步最新节点数据。
V2Ray 服务器启动后提示端口被占用，该如何处理？
先用 netstat 或 ss 工具查看占用该端口的进程（例如 `ss -ltnp`），确认是旧进程或其他服务占用。停止占用进程或修改 V2Ray 配置端口，然后重启服务并检查防火墙规则是否开放了新端口。
Mellow TUN 模式适合哪些应用？
TUN 模式拦截系统 IP 层流量，实现全局代理。适合游戏、视频、浏览器等全局应用，保证所有流量走节点，提高网络稳定性和速度，比普通 SOCKS5 代理覆盖范围更广。
Shadowrocket 能否自动更新订阅？
支持。Shadowrocket 可以设置定时更新周期，例如每隔 12 小时或每天自动刷新订阅链接，确保节点列表保持最新状态。这样无需手动更新即可长期稳定使用。
V2Ray 支持哪些传输层协议？
V2Ray 支持多种传输层，包括 TCP、mKCP、WebSocket、gRPC、QUIC 等。每种传输方式都有不同的性能特点，例如 TCP 稳定、WS 兼容 CDN、QUIC 延迟低。
SSR 协议和混淆选择如何影响稳定性？
根据网络封锁情况选择合适协议和混淆方式，如 tls1.2_ticket_auth 模拟 HTTPS 流量。合理组合可提升抗封锁能力和连接稳定性，确保节点长期可用，优化网络访问。
